# คู่มือผู้ใช้ Insightful

Insightful เป็นพื้นที่ทำงานวิเคราะห์ข้อมูลด้วย AI คุณสามารถโหลดไฟล์ CSV หรือเชื่อมต่อฐานข้อมูล สร้างกราฟ ดูการ์ดสรุปและตัวอย่างข้อมูล และถามคำถามเกี่ยวกับข้อมูลเป็นภาษาธรรมดาได้

คู่มือนี้สำหรับผู้ใช้งานทั่วไป ผู้ดูแลระบบยังต้องใช้ **คู่มือการดำเนินงาน** (`operational-guide.md`) ซึ่งครอบคลุมการตั้งค่า การสำรองข้อมูล และการอัปเดต

> หมายเหตุ: ชื่อปุ่มและข้อความบางส่วนในแอปยังแสดงเป็นภาษาอังกฤษ คู่มือนี้จึงใช้ชื่อเดียวกับที่คุณเห็นบนหน้าจอ

## 1. การเข้าสู่ระบบ

### การใช้งานครั้งแรก: สร้างซูเปอร์ยูสเซอร์

เมื่อเริ่มใช้แอปครั้งแรก ยังไม่มีบัญชีผู้ใช้ หน้าเข้าสู่ระบบจะแสดงแบบฟอร์ม **ตั้งค่า** สำหรับบัญชีซูเปอร์ยูสเซอร์

1. กรอกชื่อของคุณ อีเมล และ **รหัสตั้งค่าครั้งเดียว** ผู้ดูแลจะได้รหัสนี้จากค่า `ADMIN_SETUP_KEY` ในไฟล์ `.env` ของเซิร์ฟเวอร์
2. สร้างรหัสผ่านอย่างน้อย **12 ตัวอักษร**
3. เลือก **Create superuser** (สร้างซูเปอร์ยูสเซอร์)

### การเข้าสู่ระบบครั้งต่อไป

1. กรอกอีเมลและรหัสผ่าน
2. เลือก **เข้าสู่ระบบอย่างปลอดภัย**

ใช้ **แสดงรหัสผ่าน** / **ซ่อนรหัสผ่าน** เพื่อตรวจสอบสิ่งที่พิมพ์ได้ การเข้าสู่ระบบจะเก็บไว้ในคุกกี้ที่ปลอดภัย หากผู้ดูแลเปลี่ยนการตั้งค่าเซิร์ฟเวอร์ คุณอาจต้องเข้าสู่ระบบใหม่

> อย่าเปิดเผยรหัสผ่านของคุณ หากต้องการบัญชีให้ผู้อื่น ให้ขอให้ผู้ดูแลระบบสร้างหรือรีเซ็ตให้

## 2. ภาพรวมพื้นที่ทำงาน

หลังเข้าสู่ระบบ หน้าจอแบ่งเป็นสามส่วนหลัก

| ส่วน | หน้าที่ |
|---|---|
| **แถบด้านข้าง (ซ้าย)** | เมนูนำทาง (**ภาพรวม**, **ถาม AI**, **แหล่งข้อมูล**), **การวิเคราะห์ล่าสุด**, รายการ **Datasets**, **Date filter** และ **Display controls** บนโทรศัพท์ ให้เปิดแถบด้านข้างด้วยปุ่มเมนูที่มุมซ้ายบน |
| **แถบด้านบน** | เส้นทางหน้าปัจจุบัน ตัวเลือกภาษา สถานะระบบ การค้นหา การแจ้งเตือน **ผู้ดูแล** (เฉพาะซูเปอร์ยูสเซอร์) และ **ช่วยเหลือ** (คู่มือนี้) |
| **พื้นที่หลัก** | หัวข้อหน้า แถบ **ACTIVE DATASET** (ชุดข้อมูลที่ใช้งาน) การ์ดสรุป พื้นที่วางกราฟ และตัวอย่างข้อมูล |

### การนำทาง

- **ภาพรวม**: แดชบอร์ดที่มีการ์ดสรุป กราฟ และตัวอย่างข้อมูล
- **ถาม AI**: เปิดแผงคำถามกับ AI (ดู[หัวข้อ 6](#6-ถาม-ai))
- **แหล่งข้อมูล**: เปิดหน้าต่างเชื่อมต่อฐานข้อมูลและตารางไฟล์ CSV (ดู[หัวข้อ 7](#7-การเชื่อมต่อแหล่งข้อมูล))

## 3. การโหลดข้อมูล

Insightful ทำงานกับ **ไฟล์ CSV** (ข้อความที่คั่นด้วยเครื่องหมายจุลภาค) แถวแรกควรเป็นชื่อคอลัมน์

### อัปโหลดไฟล์ CSV

1. เลือก **อัปโหลดไฟล์** หรือ **แนบข้อมูล**
2. เลือกไฟล์ `.csv` จากคอมพิวเตอร์
3. ไฟล์นั้นจะกลายเป็นชุดข้อมูลที่ใช้งาน ชื่อไฟล์จะแสดงในแถบชุดข้อมูล และถูกเพิ่มในรายการ **Datasets** ที่แถบด้านข้าง

เมื่อโหลดชุดข้อมูลแล้ว การ์ดสรุป กราฟ ตัวอย่างข้อมูล และแผง **ถาม AI** จะใช้ชุดข้อมูลนั้น

### สลับชุดข้อมูล

คลิกชื่อชุดข้อมูลในรายการ **Datasets** เพื่อให้เป็นชุดข้อมูลที่ใช้งาน

### แก้ไขชุดข้อมูล

คลิกไอคอน **ดินสอ** ข้างชุดข้อมูลเพื่อเปลี่ยนรายละเอียด เช่น ชื่อ (Edit dataset) เมื่อเสร็จแล้วปิดหน้าต่างด้วยปุ่ม **X**

### เคล็ดลับเกี่ยวกับ CSV

- มีแถวหัวตารางหนึ่งแถว และหนึ่งระเบียนต่อหนึ่งบรรทัด
- ใช้ตัวเลขธรรมดาโดยไม่มีเครื่องหมายคั่นหลักพัน หากต้องการกราฟตัวเลข (เช่น `12500` ไม่ใช่ `12,500`)
- วันที่ควรใช้รูปแบบเดียวกันตลอด เช่น `2026-01-31`
- เซลล์ว่างใช้ได้ แต่จะไม่ถูกนับในการคำนวณ

> ไฟล์ที่อัปโหลดจะถูกอ่านในเบราว์เซอร์ของคุณ โปรดเก็บไฟล์ต้นฉบับไว้ เพราะแอปไม่ได้แก้ไขไฟล์เหล่านั้น

## 4. การกรองและการแสดงผล

แถบด้านข้างมีการควบคุมสองกลุ่มที่เปลี่ยนสิ่งที่คุณเห็น โดยไม่เปลี่ยนข้อมูลจริง

### Date filter (ตัวกรองวันที่)

- เลือกช่วงวันที่จากรายการ **Date filter** เพื่อแสดงเฉพาะแถวในช่วงเวลานั้น

### Display controls (การแสดงผล)

- **จำนวนแถวสูงสุด** (Max rows): จำกัดจำนวนแถวที่กราฟและตัวอย่างใช้ เลือก **All** เพื่อใช้ทุกแถว
- **Refresh charts**: เลือกความถี่ที่กราฟโหลดข้อมูลใหม่อัตโนมัติ

หากกราฟดูว่างเปล่า ให้ตรวจสอบ Date filter และจำนวนแถวสูงสุดก่อน

## 5. การสร้างกราฟ

กราฟจะวางบนพื้นที่กราฟในหน้า **ภาพรวม**

### สร้างกราฟ

1. เลือก **+ New chart**
2. ตั้งค่าตัวเลือก:
   - **Type**: หนึ่งในประเภทกราฟในตารางด้านล่าง
   - **ข้อมูล** (Data): ชุดข้อมูลที่ใช้ (ค่าเริ่มต้นคือ Current data)
   - **Category (X)**: คอลัมน์ที่ใช้จัดกลุ่มข้อมูล (เช่น `เดือน` หรือ `ภูมิภาค`)
   - **Value (Y)**: คอลัมน์ตัวเลขที่ต้องการวัด (เช่น `ยอดขาย`)
   - **Calculation**: วิธีรวมค่าในแต่ละหมวดหมู่ (ดูด้านล่าง)
   - **Columns**: สำหรับตาราง ให้เลือกคอลัมน์ที่จะแสดง เลือก **Show all** เพื่อรีเซ็ต
   - **Width** และ **Title**: การจัดวางและชื่อกราฟ
3. คลิกบนพื้นที่กราฟตรงตำแหน่งที่ต้องการให้กราฟปรากฏ กด **Esc** หรือเลือก **Cancel** เพื่อหยุดการวาง

### ประเภทกราฟ

| ประเภท | ใช้สำหรับ |
|---|---|
| **Line graph** | แนวโน้มตามเวลา |
| **Bar graph** | เปรียบเทียบหมวดหมู่ |
| **Donut** | สัดส่วนของทั้งหมด เมื่อมีหมวดหมู่ไม่มาก |
| **Histogram** | การกระจายของค่าในแต่ละช่วง |
| **Box plot** | ค่ามัธยฐาน การกระจาย และค่าผิดปกติของคอลัมน์ตัวเลข |
| **Card (single value)** | ตัวเลขสรุปเพียงค่าเดียว |
| **Table** | ค่าจริงในคอลัมน์ที่เลือก |

### การคำนวณ

| การคำนวณ | ความหมาย |
|---|---|
| **Sum** | ค่ารวมของทุกค่า |
| **ค่าเฉลี่ย** (Average) | ค่าเฉลี่ยของทุกค่า |
| **Count** | จำนวนแถว |
| **Minimum** | ค่าที่น้อยที่สุด |
| **Maximum** | ค่าที่มากที่สุด |

### ย้าย ปรับ และแก้ไข

- ย้ายกราฟโดยลากบนพื้นที่กราฟ เมื่อเปิด **Show grid** กราฟจะยึดกับตารางกริด ขนาดของช่องตารางตั้งไว้ข้างกัน (Grid size)
- ใช้ไอคอน **เฟือง** เพื่อเปิด **Chart settings** และเปลี่ยนตัวเลือกใดก็ได้ที่กล่าวมาข้างต้น
- ใช้ไอคอน **ประกาย** เพื่อ **Analyze with AI** และขอคำอธิบายของกราฟนั้น
- ใช้ไอคอน **X** เพื่อลบกราฟ การลบกราฟไม่เปลี่ยนแปลงข้อมูลของคุณ

หากกราฟแสดงข้อความภาษาอังกฤษต่อไปนี้:

- **Choose a category column** / **Choose a value column**: ให้ตั้งค่าคอลัมน์ที่ขาดหายในการตั้งค่ากราฟ
- **No numeric values.**: คอลัมน์ค่าไม่มีตัวเลข ให้เลือกคอลัมน์ตัวเลขหรือตรวจสอบไฟล์ CSV
- **Could not load this data.** (โหลดข้อมูลนี้ไม่ได้): ตรวจสอบเซิร์ฟเวอร์แล้วลองใหม่

## 6. ถาม AI

ถาม AI ตอบคำถามเกี่ยวกับข้อมูลของคุณเป็นภาษาธรรมดา ใช้ได้ในหน้า **ถาม AI** และผ่านปุ่ม **ถาม AI** แบบลอยด้วย

> ถาม AI ต้องมีคีย์ API ของ OpenRouter และโมเดล ซูเปอร์ยูสเซอร์เป็นผู้ตั้งค่าในหัวข้อ **ผู้ดูแล → ผู้ให้บริการ OpenRouter** (ดู[หัวข้อ 9](#9-การดูแลระบบ)) หากยังไม่ได้ตั้งค่า แผงจะขอให้คุณ **ตั้งค่า OpenRouter**

### ถามคำถาม

1. เปิด **ถาม AI**
2. ตรวจสอบตัวเลือกขอบเขต: **Whole dashboard** ใช้การ์ดและกราฟทั้งหมด หากไม่เลือก จะใช้เฉพาะชุดข้อมูลที่ใช้งาน
3. พิมพ์คำถามในช่อง (เช่น *"ภูมิภาคไหนมียอดขายสูงสุดในไตรมาสที่แล้ว"*) แล้วเลือก **ส่งคำถาม**
4. รอระหว่างที่ระบบเตรียมคำตอบ ซึ่งอาจใช้เวลาไม่กี่วินาที
5. ใช้ **Copy answer** เพื่อคัดลอกข้อความ หรือ **ล้างคำตอบ** เพื่อเริ่มใหม่

คุณยังเริ่มจาก **คำถามแนะนำ** ที่แสดงในแผงได้ด้วย

### วิเคราะห์กราฟเดียว

ใช้ไอคอน **ประกาย** บนกราฟเพื่อขอคำอธิบายเฉพาะกราฟนั้น

### ข้อควรทราบ

- คำตอบอิงจากแถวข้อมูลที่โหลดในแอป ควรตรวจสอบตัวเลขสำคัญกับไฟล์ต้นฉบับอีกครั้ง
- ส่งเฉพาะข้อมูลที่คุณได้รับอนุญาตให้แชร์กับบริการ AI ที่ผู้ดูแลระบบกำหนดไว้เท่านั้น

## 7. การเชื่อมต่อแหล่งข้อมูล

เลือก **แหล่งข้อมูล** ในแถบด้านข้างเพื่อเปิดหน้าต่าง **Connect data** (เชื่อมต่อข้อมูล)

| แหล่งข้อมูล | สถานะ |
|---|---|
| **CSV** | ใช้ได้ เลือกตาราง CSV ที่เก็บอยู่ในเซิร์ฟเวอร์แล้ว ดูตัวอย่าง และนำไปใช้ได้ นอกจากนี้ยังแปลงตาราง CSV เป็นตารางฐานข้อมูลได้ด้วย |
| **PostgreSQL** หรือ **MySQL** | ใช้ได้ กรอกลิงก์การเชื่อมต่อ ทดสอบการเชื่อมต่อ เลือกตาราง ดูตัวอย่าง (สูงสุด 50 แถว) แล้วเลือก **Use this data** |
| **Google Sheets / Google Drive** | ยังไม่พร้อมใช้งาน |

### เชื่อมต่อ PostgreSQL หรือ MySQL

1. เปิด **แหล่งข้อมูล** แล้วเลือก **PostgreSQL** หรือ **MySQL**
2. กรอกที่อยู่การเชื่อมต่อในรูปแบบ `postgresql://user:password@host:port/database` (หรือ `mysql://…`) สำหรับ MySQL ที่ต้องใช้ TLS ให้เพิ่ม `?ssl=true` ที่ท้ายลิงก์
3. เลือก **ทดสอบการเชื่อมต่อ**
4. เลือกตารางและตรวจสอบตัวอย่างข้อมูล
5. เลือก **Use this data** เพื่อแสดงตารางในแดชบอร์ด

รายละเอียดการเชื่อมต่อจะถูกส่งไปยังเซิร์ฟเวอร์ในทุกคำขอ และไม่ถูกบันทึกโดยฟีเจอร์นี้ หากบันทึกการเชื่อมต่อไว้ รหัสผ่านจะถูกเข้ารหัสบนเซิร์ฟเวอร์

> เชื่อมต่อเฉพาะฐานข้อมูลและตารางที่คุณมีสิทธิ์เข้าถึงเท่านั้น

## 8. ภาษา

ใช้ตัวเลือกภาษาในแถบด้านบนเพื่อสลับระหว่าง **EN** (อังกฤษ) และ **ไทย** การเลือกนี้มีผลกับส่วนติดต่อผู้ใช้ ส่วนข้อมูลของคุณจะไม่ถูกแปล

เมื่อเลือกภาษาไทย คู่มือนี้จะแสดงเป็นภาษาไทยด้วย

## 9. การดูแลระบบ

ปุ่ม **ผู้ดูแล** ในแถบด้านบนมองเห็นได้เฉพาะซูเปอร์ยูสเซอร์ หน้าต่างผู้ดูแลมีส่วนดังนี้

| ส่วน | หน้าที่ |
|---|---|
| **ฐานข้อมูลของแอปพลิเคชัน** | เลือกที่เก็บผู้ใช้และการตั้งค่าของแอป ได้แก่ SQLite3 (ค่าเริ่มต้น), MySQL หรือ PostgreSQL ใช้ **ทดสอบการเชื่อมต่อ** ก่อน **บันทึกและสลับ** |
| **บัญชีซูเปอร์ยูสเซอร์** | เปลี่ยนชื่อและอีเมลของคุณ และอัปเดตรหัสผ่าน |
| **ผู้ให้บริการ OpenRouter** | ตั้งค่าคีย์ API และโมเดลเริ่มต้นที่ถาม AI ใช้ ระบบจะเก็บคีย์ไว้อย่างเข้ารหัส |
| **ผู้ใช้ในพื้นที่ทำงาน** | ดูบัญชีผู้ใช้ในพื้นที่ทำงาน |

ควรมีบัญชีซูเปอร์ยูสเซอร์อย่างน้อยหนึ่งบัญชีเสมอ สำหรับการตั้งค่าเซิร์ฟเวอร์ การสำรองข้อมูล และความลับของระบบ ดู **คู่มือการดำเนินงาน**

## 10. เคล็ดลับและการแก้ปัญหา

| ปัญหา | สิ่งที่ควรลอง |
|---|---|
| หน้าว่างหรือแสดงข้อผิดพลาด | รีเฟรชเบราว์เซอร์ หากยังมีปัญหา ให้ขอให้ผู้ดูแลตรวจสอบว่าเซิร์ฟเวอร์ทำงานอยู่ |
| กราฟว่างเปล่า | ตรวจสอบ **Date filter** **จำนวนแถวสูงสุด** และคอลัมน์ Category (X) กับ Value (Y) ของกราฟ |
| ตัวเลขดูผิด | ตรวจสอบไฟล์ CSV ว่ามีข้อความในคอลัมน์ตัวเลข เครื่องหมายคั่นหลักพัน หรือรูปแบบวันที่ที่ปนกันหรือไม่ |
| **ถาม AI** แจ้งว่ายังไม่ได้ตั้งค่า | ผู้ดูแลต้องตั้งค่าคีย์ OpenRouter และโมเดลในหัวข้อ **ผู้ดูแล** |
| คำตอบของ **ถาม AI** ล้มเหลวหรือช้า | ลองใหม่อีกครั้ง หรือถามคำถามที่สั้นลง และตรวจสอบการเชื่อมต่ออินเทอร์เน็ต |
| หน้าต่างช่วยเหลือไม่เปิด | อนุญาต pop-up สำหรับเว็บไซต์นี้ในเบราว์เซอร์ แล้วเลือก **ช่วยเหลือ** อีกครั้ง |
| เชื่อมต่อฐานข้อมูลไม่สำเร็จ | ตรวจสอบ host, port, ชื่อผู้ใช้, รหัสผ่าน และการตั้งค่า TLS กับผู้ดูแลฐานข้อมูล |
| ออกจากระบบโดยไม่คาดคิด | เข้าสู่ระบบใหม่ ผู้ดูแลอาจเปลี่ยนการตั้งค่าเซสชันของเซิร์ฟเวอร์ |

## 11. คำศัพท์

- **ชุดข้อมูลที่ใช้งาน** (Active dataset): ข้อมูลที่แดชบอร์ด กราฟ และ ถาม AI กำลังใช้อยู่
- **Category (X)**: คอลัมน์ที่ใช้จัดกลุ่มค่า แสดงตามแนวนอน
- **Value (Y)**: คอลัมน์ตัวเลขที่ใช้วัดผล
- **Calculation**: วิธีรวมค่าในแต่ละหมวดหมู่ (Sum, Average, Count, Minimum, Maximum)
- **ซูเปอร์ยูสเซอร์** (Superuser): บัญชีผู้ดูแลที่เปลี่ยนการตั้งค่าแอปและจัดการผู้ใช้ได้
- **OpenRouter**: บริการ AI ที่ตอบคำถามในถาม AI
- **TLS**: การเชื่อมต่อฐานข้อมูลที่เข้ารหัส ผู้ให้บริการคลาวด์มักกำหนดให้ใช้
